# New Song Experience

> **Start a song like starting a conversation—but YOU stay the writer.**

## The Problem

### What ChatGPT Does (Wrong for Songwriting)

```
User: "I'm starting a song about hope after a breakup. I have a few
       lines like 'still see your face in the morning light', but
       I'm not sure if there's a hook. Help me build the song."

ChatGPT: "Here's a complete song for you:

          [Verse 1]
          Still see your face in the morning light
          Memories haunting through the night
          But I'm learning to let go...

          [Chorus]
          This is hope rising..."
```

**Problem:** The AI wrote the song. The user is no longer the writer—they're an editor of AI content. That's not songwriting, that's prompt engineering.

---

## Greg's Approach

### Start a Conversation, Not a Generation

```
User: "I'm starting a song about hope after a breakup. I have a few
       lines like 'still see your face in the morning light', but
       I'm not sure if there's a hook. Help me build the song."

Greg: "Nice starting point. That line has a melancholy morning
       imagery—very visual. Let me help you explore this.

       A few questions to find the hook:

       1. What's the turning point? When does hope enter?
       2. Is this looking back, or looking forward?
       3. What do you want the listener to feel at the end?

       Also, I noticed 'morning light'—is there a day/night
       metaphor running through this? That could be your hook."
```

**Key difference:** Greg asks questions, surfaces patterns, and helps YOU discover the song—it doesn't write it for you.

## Core Principles

### 1. Guide, Don't Generate

| ChatGPT Approach | Greg Approach |
|------------------|---------------|
| "Here's your verse" | "What happens in the verse?" |
| Writes the hook | "I see a potential hook in your imagery" |
| Completes the song | "Let's build a structure together" |
| User edits AI content | User writes with AI support |

### 2. Structure Before Lyrics

Before writing a single lyric, establish:

```
┌─────────────────────────────────────────────────────┐
│  SONG SHAPE                                         │
├─────────────────────────────────────────────────────┤
│  Theme: Hope after heartbreak                       │
│  Emotional arc: Pain → Acceptance → Hope            │
│  Key images: Morning light, letting go              │
│  Potential hook: Day/night metaphor                 │
│  Structure: Verse → Chorus → Verse → Bridge → Out   │
└─────────────────────────────────────────────────────┘
```

The user can SEE the shape before filling it in.

### 3. Accept Anything as Input

Users might start with:

| Input Type | Example |
|------------|---------|
| **Theme** | "A song about leaving home" |
| **Fragments** | "I have these lines: 'walking out the door...'" |
| **Melody** | Audio humming or description |
| **Feeling** | "Something that feels like early Coldplay" |
| **Reference** | "Similar vibe to 'Let Her Go'" |
| **Story** | "My grandmother passed and I want to write about her" |
| **Chords** | "I have this progression: Am - F - C - G" |

Greg handles ALL of these and helps structure them.

## Conversation Flow

### Phase 1: Intake

```
┌─────────────────────────────────────────────────────────┐
│  NEW SONG                                               │
│                                                         │
│  What do you want to write about?                       │
│                                                         │
│  ┌─────────────────────────────────────────────────┐   │
│  │ I'm starting a song about hope after a breakup. │   │
│  │ I have a few lines like "still see your face    │   │
│  │ in the morning light", but I'm not sure if      │   │
│  │ there's a hook. Help me build the song.         │   │
│  └─────────────────────────────────────────────────┘   │
│                                                         │
│  [Start Writing]                                        │
└─────────────────────────────────────────────────────────┘
```

### Phase 2: Exploration

Greg responds with:
1. **Acknowledgment** - What it heard
2. **Questions** - To deepen understanding
3. **Observations** - Patterns it noticed
4. **Suggestions** - Possible directions (not lyrics)

```
Greg: "I hear a song about hope emerging from heartbreak. Your line
       'still see your face in the morning light' is evocative—
       morning as both literal and metaphorical.

       Let me understand more:

       • Is this hope already present, or are you searching for it?
       • When you picture the song finished, what's the ending feel?
       • Any other fragments, words, or images floating around?"
```

### Phase 3: Structure Building

As the conversation progresses, Greg builds a visible structure:

```
┌─────────────────────────────────────────────────────────┐
│  SONG SHAPE (building...)                               │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  Theme: Hope after heartbreak                           │
│  Arc: [Pain] ──────────────────────────────► [Hope]    │
│                    ↑                                    │
│              (turning point?)                           │
│                                                         │
│  Key Images:                                            │
│  • "morning light" - visual, temporal                   │
│  • (more to discover)                                   │
│                                                         │
│  Possible Structure:                                    │
│  ┌─────┐ ┌─────────┐ ┌─────┐ ┌──────┐ ┌───────┐       │
│  │Verse│→│ Chorus  │→│Verse│→│Bridge│→│Chorus │       │
│  │pain │ │ hook?   │ │shift│ │turn  │ │hope   │       │
│  └─────┘ └─────────┘ └─────┘ └──────┘ └───────┘       │
│                                                         │
│  [Add to song] [Keep exploring]                         │
└─────────────────────────────────────────────────────────┘
```

### Phase 4: Transition to Writing

When the user is ready, Greg doesn't generate—it sets up the canvas:

```
Greg: "I think we have enough to start. Here's what we've built:

       [Creates song with sections]

       VERSE 1 - The morning, the memory, the pain
       CHORUS - (hook: the light metaphor—you'll write this)
       VERSE 2 - The shift, starting to let go
       BRIDGE - The turning point
       CHORUS - Hope arrives

       I've added placeholder notes to each section.
       Where do you want to start writing?"
```

The song is created with:
- Section types defined
- Emotional intent per section
- User's fragments placed appropriately
- But NO AI-written lyrics

---

## What Greg Creates vs. What User Writes

| Greg Creates | User Writes |
|--------------|-------------|
| Section structure | All lyrics |
| Emotional arc notes | The actual words |
| Placement of fragments | New lines |
| Theme summary | The hook |
| Potential chord suggestions | Final chord choices |

**The song is a canvas, not a draft.**

## Anti-Patterns (What Greg Should NOT Do)

| Anti-Pattern | Why It's Bad |
|--------------|--------------|
| Write a complete verse | User becomes editor, not writer |
| Suggest specific lyrics | Pollutes user's creative voice |
| Rush to structure | Some songs need more exploration |
| Assume genre/style | Let user's voice emerge |
| Over-explain music theory | Songwriter, not student |
| Generate multiple options | Analysis paralysis |

## Comparison to Session Mode

This IS Session Mode, but specifically for new songs:

| Session Mode (General) | New Song Experience |
|------------------------|---------------------|
| Can happen anytime | Specifically at song creation |
| Explores ideas | Builds initial structure |
| Outputs to existing song | Creates new song |
| Open-ended | Ends with structured canvas |

## Implementation Considerations

### API Flow

```
POST /songs/start
{
  "initial_input": "I'm starting a song about hope...",
  "input_type": "freeform"  // or "fragments", "melody", "chords"
}

→ Returns: { "session_id": "...", "song_id": null }

// Conversation happens via WebSocket
WS /songs/session/{session_id}

→ { "type": "message", "content": "..." }
← { "type": "response", "content": "...", "song_shape": {...} }

// When ready to transition
POST /songs/session/{session_id}/create
{
  "confirm": true
}

→ Returns: { "song_id": "...", "sections": [...] }
```

### UI States

1. **Blank slate** - Just the input box
2. **Conversing** - Chat + emerging song shape
3. **Structure preview** - Full structure before creation
4. **Transition** - Create song with structure
5. **Writing** - In the editor with sections ready

## Success Criteria

| Metric | Target |
|--------|--------|
| User writes first lyric | Within 5 minutes of starting |
| User feels like the writer | Post-session survey |
| Structure helps, not constrains | User modifies structure freely |
| Fragments get placed correctly | 90%+ satisfaction |
| Song feels personal | "This is MY song" |

## Example Conversations

### Starting with Theme

```
User: "A song about leaving home for the first time"

Greg: "That's a universal moment—exciting and scary. Tell me more:

       • Are you leaving, or did you already leave?
       • What's the dominant emotion: freedom? guilt? fear? hope?
       • Is there a specific moment you keep coming back to?"
```

### Starting with Fragments

```
User: "I have these lines: 'packing up my childhood room /
       boxes full of memories / mom standing in the doorway'"

Greg: "Beautiful imagery—very cinematic. The mom in the doorway
       is powerful.

       These feel like verse lines—specific, narrative.

       What's the chorus going to SAY? Not the words, but the
       feeling. What's the emotional truth these images point to?"
```

### Starting with Chords

```
User: "I have Am - F - C - G, feels kind of melancholy but hopeful"

Greg: "Classic progression—works in a lot of contexts. The Am start
       gives it that bittersweet quality you're feeling.

       What story fits this mood for you?
       Any words or phrases that come up when you play it?"
```
